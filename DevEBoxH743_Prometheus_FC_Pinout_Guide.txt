================================================================================
                    WHAT TO CONNECT TO EACH SERIAL PORT
================================================================================

 SERIAL1 (USART1) - GPS MODULE
 ─────────────────────────────
   PA9  (TX) ────► GPS RX
   PA10 (RX) ◄──── GPS TX
   Recommended: u-blox M10, M9N, M8N
   Protocol: 5 (GPS), Baud: 115200
   Also connects: I2C compass on GPS module (use I2C2: PB10/PB11)

 SERIAL2 (USART2) - RADXA / COMPANION COMPUTER
 ──────────────────────────────────────────────
   PD5 (TX) ────► Radxa RX (UART)
   PD6 (RX) ◄──── Radxa TX (UART)
   Protocol: 2 (MAVLink2), Baud: 115200
   Use: Radxa Cubie A7S, Raspberry Pi, Jetson, etc.
   WARNING: STM32 is 3.3V logic! Use level shifter if companion is 5V.

 SERIAL3 (USART3) - TELEMETRY / RADIO LINK
 ──────────────────────────────────────────
   PD8 (TX) ────► Telem Radio RX
   PD9 (RX) ◄──── Telem Radio TX
   Protocol: 2 (MAVLink2), Baud: 57600
   Use: SiK radio, LoRa telemetry, ESP32 WiFi bridge

 SERIAL4 (UART4) - RC RECEIVER INPUT
 ────────────────────────────────────
   PB8 (RX) ◄──── RC Receiver Signal (SBUS/CRSF/ELRS)
   PB9 (TX) ────► RC Receiver (for CRSF/ELRS bidirectional)
   Protocol: 23 (RCIN), Baud: 230400
   Supported: SBUS, CRSF (Crossfire/ELRS), IBUS, SUMD, DSM
   NOTE: For SBUS, you need an inverter or set BRD_ALT_CONFIG.

 SERIAL5 (USART6) - SPARE
 ────────────────────────
   PC6 (TX)
   PC7 (RX)
   Default: Disabled (-1). Can be used for:
   - Second GPS, Rangefinder (Lidar), Optical Flow, Beacon, etc.

 SERIAL6 (UART7) - SPARE / DEBUG
 ────────────────────────────────
   PE8 (TX)
   PE7 (RX)
   Default: Disabled (-1). Can be used for debug console or peripherals.

 SERIAL7 (UART8) - SPARE
 ────────────────────────
   PE1 (TX)
   PE0 (RX)
   Default: Disabled (-1). Can be used for any serial peripheral.

================================================================================
                           I2C BUSES (2 ACTIVE)
================================================================================

 Bus    SCL     SDA     ArduPilot    Use
        Pin     Pin     Bus Index
 ──────────────────────────────────────────────────────
 I2C1   PB6     PB7     Bus 0        Barometer + Compass (internal)
 I2C2   PB10    PB11    Bus 1        External sensors / GPS compass

 NOTE: I2C requires 4.7kΩ pull-up resistors to 3.3V on both SCL and SDA.
       Many breakout modules include pull-ups. Don't double up.

 BAROMETER (on I2C1 / Bus 0):
   DPS310 at address 0x76 (preferred)
   MS5611 at address 0x77 (alternative)
   Wiring: VCC=3.3V, GND, SCL=PB6, SDA=PB7

 COMPASS (on I2C1 or I2C2):
   External compass (e.g., HMC5883L, QMC5883L, IST8310, RM3100)
   GPS modules with built-in compass: connect compass I2C to I2C2 (PB10/PB11)
   ArduPilot auto-probes common compass addresses.

 OTHER I2C SENSORS YOU CAN CONNECT:
   - Airspeed sensor (MS4525DO, DLVR, etc.)
   - Optical flow (PMW3901 via I2C)
   - LED controller (NCP5623, TCA62724)
   - Power monitor (INA226, INA228)
   - OLED display

================================================================================
                    POWER SUPPLY NOTES
================================================================================

 • DevEBox has a 3.3V regulator on board (powered from USB or 5V input)
 • DO NOT connect ESC battery voltage (11.1V-14.8V) to the board!
 • Power the board from:
   - USB-C (for testing/configuration)
   - 5V BEC from PDB/ESC (in-flight power)
 • All GPIO pins are 3.3V logic. Do NOT connect 5V signals directly.
 • I2C/SPI sensors must be 3.3V compatible.

================================================================================
                           NOTES & WARNINGS
================================================================================

 1. The firmware was built and verified on: June 26, 2026
 2. ArduCopter version: V4.8.0-dev (commit 919569ac)
 3. ADC is ENABLED on PA2 (Voltage, pin 14) and PA3 (Current, pin 15).
    Connect your power module's analog sense wires to these pins.
 4. CAN bus is ENABLED (CAN1). Connect a CAN transceiver to PD0/PD1
    to use DroneCAN peripherals like GPS or smart batteries.
 5. No SBUS inverter is configured. For SBUS RC receivers, you may need
    an external SBUS inverter circuit, or use CRSF/ELRS instead.
 6. PC14 may be occupied by LSE 32K crystal on some DevEBox revisions.
 7. Always test motor direction and order before first flight!
 8. Calibrate accelerometer, compass, and radio before flying.
